========================================================================
  Vinta OS - what this USB stick is for
========================================================================

For whoever is taking it to the school: you need to do exactly two things.

  1. Plug the stick into the school's computer.
  2. Open the stick and double-click:   Setup.exe

That is the whole job. Setup installs Vinta OS, prepares its database, and
puts a Vinta OS icon on the Desktop and in the Start Menu.

Afterwards, the staff start the program by double-clicking:

        Vinta OS   (the icon on the Desktop)

Nothing on this stick needs the internet, and nothing has to be installed
beforehand. Setup does not need an administrator password.


------------------------------------------------------------------------
  IF WINDOWS SHOWS A BLUE WARNING
------------------------------------------------------------------------

  "Windows protected your PC"

  This appears because the program is not signed with a paid certificate.
  It is not a warning about a virus. Click:

        More info    ->    Run anyway


------------------------------------------------------------------------
  WHAT SETUP DOES, IN PLAIN WORDS
------------------------------------------------------------------------

  Program installed here:
        %LOCALAPPDATA%\Vinta OS

  The school's records are kept here:
        %APPDATA%\Vinta OS

  Those two are kept apart on purpose. Updating the program later means
  running a new Setup.exe over the top, and your records are untouched,
  because they live somewhere else.


------------------------------------------------------------------------
  FIRST TIME INSIDE THE PROGRAM
------------------------------------------------------------------------

  The program starts with nothing in it, so the school sets it up the way
  they want. On the login screen choose the "Sign up" tab and enter:

        - the academy's name
        - the owner's email address and a password (8+ characters)
        - a 4-digit PIN

  That creates the academy and the owner account. Staff profiles are added
  from inside the program afterwards.


------------------------------------------------------------------------
  BEFORE YOU HAND OVER THE STICK
------------------------------------------------------------------------

  Copy the ENTIRE contents of this folder onto the stick - Setup.exe, the
  "Vinta OS" folder, and this file. Setup reads the program from the
  "Vinta OS" folder next to it, so the two must stay together.


------------------------------------------------------------------------
  TO REMOVE IT AGAIN
------------------------------------------------------------------------

  Windows Settings -> Apps -> Installed apps -> Vinta OS -> Uninstall

  or double-click Uninstall.exe inside the install folder.

  Uninstalling keeps the school's records by default, so the program can
  be reinstalled without losing anything. It asks before deleting them.
