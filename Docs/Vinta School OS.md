Vinta School OS main concept
I. Summary and Overview

First of, The main concept is to replace the pen and paper for local schools, academies and kinder gardens, so we get our Vinta OS, we market as luxury, fully functional operating system (Well kind of CRM) where the front disk staff can follow the kids, teachers, class status to fully remove the "I will remember" and the "I think he didn't came last week" and for kinder gardens the "Why is my kid picked by my devorced wife"

II. The features on the OS

1. Each attender profile with: Full name, Age, Phone numbers, classes, payment logs, notes, gardens and a calendar with the payments and the classes. 
2. Each teacher profile: Full name, Phone number, classes, hours taught, notes. 
3. An automated log will be regestered the moment a kid get's out of the class
4. Class follow: When a class is full it shows up in red, when a class is not full but people are studying you get yellow, when it's empty and not teaching it's green

III. Coloring and Style

First off, we have 3 colors tones, the base colors for the background are: 1- glossy off-white 2- Emerald 3- Gold

And for Dark mode, we just swap the Off-white with Deep Dark Grey. (As presented in this file) ![[vinta_theme_preview.html]] Second, for the overall style we want something that looks like an Apple product, similar to how IOS and MacOS looks, (Water Glass, rounded edges, clean styling, clean Animations, user friendly), to be exact similar to how "Contacts" work in iPhone (the list and the expand style) same thing we use.

IV. The Roles And Backend:

**Now when it comes to the back end part We keep it lean, we don't use any fancy logging systems, just a list and the staff search the name and click log as present.

**As for how the profiles will be we will have:

1- Super Admin: This is the business owner, he can control anything (Profiles, Staff Profiles, classes, billing csv...etc) and has access to all logs from a tab in his profile 
2- Staff (Front Disk): so basically they can log attendants, create profiles, edit profiles, add billing, add teachers and select classes...etc
